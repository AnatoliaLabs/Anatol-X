01 / Neden Anatol-X? 01 / Why Anatol-X?

Temeli sağlam.
Yolu açık. Built on a solid
foundation.

Tanıdık bir altyapıyı, kişiselleştirilebilir bir masaüstü ve Anatolia Labs araçlarıyla bir araya getiriyoruz. We bring a familiar foundation together with a customizable desktop and tools from Anatolia Labs.

01 / BASE↗

Debian 13 Trixie

Debian’ın kararlı sürümünü temel alan bir sistem. Testing değil; Trixie tabanlı. Built on Debian’s stable release. Based on Trixie, not Debian Testing.

02 / DESKTOP✳

KDE Plasma 6

Görünümü ve çalışma alanını kendine göre düzenleyebileceğin modern bir masaüstü. Varsayılan oturum Wayland. A modern, customizable desktop. The default session uses Wayland.

03 / KERNEL⌁

Liquorix

Yeni amd64 ISO’da, masaüstü odaklı Liquorix çekirdeği ve eşleşen başlık paketleri kullanılıyor. The new amd64 ISO uses the desktop-oriented Liquorix kernel and matching headers.

04 / BROWSER↗

Anatolium

Firefox ESR üzerine kurulu, Anatolia Labs tarafından geliştirilen arayüze sahip sistem tarayıcısı. A system browser built on Firefox ESR with an interface developed by Anatolia Labs.

05 / UPDATES◇

İmzalı paketler Signed packages

Anatol-X uygulamaları ve sistem paketleri, imza doğrulaması kullanılan APT deposu üzerinden dağıtılıyor. Anatol-X applications and system packages are distributed through a signature-verified APT repository.

06 / IDENTITY✦

Kendine özgü Made to feel distinct

Anatol-X kimliği, masaüstünden canlı ISO ve kurulu sistem için hazırlanan GRUB temasına uzanıyor. Anatol-X’s identity extends from the desktop to the GRUB theme prepared for the live ISO and installed system.

02 / İçinde neler var? 02 / Under the hood

Detaylar
önemlidir. Details
matter.

Anatol-X hâlâ geliştiriliyor. Aşağıdaki bilgiler mevcut ISO yapılandırmasını anlatır; yayımlanmadan önce değişebilir. Anatol-X is still in development. These details describe the current ISO configuration and may change before release.

Liquorix çekirdeği standart Secure Boot için imzalı değildir; uygun özel imzalama olmadan Secure Boot’u kapatmak gerekebilir. Donanım ve sürücü uyumluluğu test edilmelidir. The Liquorix kernel is not signed for standard Secure Boot; disabling Secure Boot may be necessary without a suitable custom signing setup. Hardware and driver compatibility should be tested.
